# Dynamic Resume Screening and Interview Automation System

A web-based recruitment management system designed to automate resume screening and simplify the interview process for recruiters and HR teams.

## Features

- Resume Upload & Analysis
- Skill-Based Candidate Filtering
- Fresher & Experienced Candidate Separation
- Automated Interview Mail Support
- Candidate Profile Comparison
- User-Friendly Interface
- HR Workload Reduction

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Workflow

1. Upload candidate resumes
2. Analyze resume content
3. Filter candidates based on skills and experience
4. Separate fresher and experienced applicants
5. Automate interview mail process

## Purpose

The main objective of this project is to simplify recruitment workflows by automating resume screening and interview management processes.
